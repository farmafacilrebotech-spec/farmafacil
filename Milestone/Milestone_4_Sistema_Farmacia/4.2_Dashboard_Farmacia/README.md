## Implementación

### Estadísticas mostradas
| Métrica | Descripción |
|---------|-------------|
| Pedidos hoy | Número de pedidos recibidos hoy |
| Ventas del mes | Total de ventas en el mes actual |
| Productos activos | Cantidad de productos en catálogo |
| Pedidos pendientes | Pedidos que requieren acción |

### Layout del dashboard
```
┌─────────────────────────────────────────────┐
│  Header (Bienvenida + Nombre Farmacia)      │
├──────────┬──────────┬──────────┬───────────┤
│ Pedidos  │  Ventas  │Productos │ Pendientes│
│   Hoy    │   Mes    │ Activos  │           │
├──────────┴──────────┴──────────┴───────────┤
│              Pedidos Recientes              │
│         (Tabla con últimos 5 pedidos)       │
├─────────────────────────────────────────────┤
│              Accesos Rápidos                │
│  [Productos] [Pedidos] [Conversaciones]     │
└─────────────────────────────────────────────┘
```
