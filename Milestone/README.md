## 🛠️ Stack Tecnológico

- **Framework:** Next.js 14 (App Router)
- **UI:** React + ShadCN + Tailwind CSS
- **Backend:** Supabase (PostgreSQL)
- **Autenticación:** Sistema personalizado con cookies
- **IA:** OpenAI GPT-4
- **QR:** qrcode.react
- **Lenguaje:** TypeScript
